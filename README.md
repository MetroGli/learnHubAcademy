\# LearnHub



Plataforma web para la gestión de cursos.



\## Descripción



LearnHub es una plataforma educativa web orientada a la gestión de

cursos, estudiantes, profesores, contenidos, evaluaciones y

calificaciones.



\## Stack tecnológico



\- React

\- Spring Boot

\- PostgreSQL

\- Docker
